# Working on this project

- **Before any visual or UI change, read `DESIGN.md`.** It is the design system: colour
  variables, fonts, the radius scale, and how buttons, inputs, dropdowns and cards look. Reuse
  the classes and `components/ui` components it names instead of writing new inline styles.
- `PRODUCT.md` describes who the site is for and what it must never do (e.g. no invented market
  data).
- The client's brief is to keep the existing look. Don't restyle things outside the task.
- Check UI changes in both the dark theme and the light theme (`body.light`).
